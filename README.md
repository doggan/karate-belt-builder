# karate-belt-sim

Preview a customized karate belt on a dogi in 3D, and share the customization as a link.

See [PLAN.md](PLAN.md) for scope, architecture and roadmap.

## Develop

```sh
npm install
npm run dev        # http://localhost:5173
npm test           # unit tests
npm run build      # typecheck + production build to dist/
npm run model      # rebuild public/models/dogi.glb from assets/models/dogi-source.glb
```
